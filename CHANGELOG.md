# Changelog

All notable changes to Dragon Scrolls Character Generator will be documented in this file.

This project uses simple version numbers:

- `v0.1.0` = first public test release
- `v0.2.0` = next feature update
- `v1.0.0` = first mature release

## [Unreleased]

Planned or in-progress ideas:

- improved PDF character sheet layout

- more dice roller features
- party manager ideas
- game master tools
- more portrait workflow improvements

## [v0.1.0] - First Public Test Release

Initial public test release of Dragon Scrolls.

### Added

- Retro fantasy character generator
- Character species, class, subclass, background, alignment, sex, level, and ability score generation
- Character roleplay trait generation
- Spell, feature, equipment, and combat stat generation
- Saved character support
- Saved character searching, sorting, loading, editing, and deleting
- Printable PDF export
- Portrait prompt generation
- Support for attaching portrait image files
- Large portrait preview window
- Built-in dice roller
- Natural 20 and Natural 1 callouts in the dice roller
- Desktop batch launcher
- Custom 80s fantasy app icon
- GitHub README
- Public roadmap
- Bug report and feature request templates
- README screenshots

### Notes

This is an early hobby release. Bugs are expected.

Dragon Scrolls currently requires Python 3.12 or newer and the packages listed in `requirements.txt`.
