# Dragon Scrolls Roadmap

This roadmap is a living document. It may change as the project grows and users provide feedback.

Dragon Scrolls is currently an early public test project. The main goal right now is to make the app easier to install, easier to use, and more useful for tabletop RPG players and game masters.

## Current Version

### v0.1.0 — First Public Test Release

Current features include:

* retro fantasy character generation
* class, subclass, species, background, alignment, and level options
* ability scores and combat stats
* spells, features, equipment, and roleplay traits
* saved character loading and searching
* printable PDF export
* portrait prompt support
* portrait image support
* built-in dice roller
* desktop batch launcher
* custom app icon

## Near-Term Goals

These are the next features most likely to be worked on.

### Easier Installation

* Create a cleaner Windows download package.
* Eventually create a Windows `.exe` version.
* Reduce the need for users to manually install Python packages.

### Better Character Editing

* Improve editing of generated character details.
* Add easier editing for equipment, spells, traits, and notes.
* Make saved character updates more intuitive.

### Better PDF Output

* Improve the visual style of exported character sheets.
* Add multiple PDF sheet themes.
* Add cleaner portrait placement.
* Add a more printer-friendly layout.

### Better Dice Roller

* Improve the dice roller layout.
* Add more common tabletop quick-roll options.
* Add clearer attack/check/damage roll formatting.
* Consider simple dice roll animations later.

## Medium-Term Ideas

These are strong possibilities, but not guaranteed yet.

### Party Manager

A tab or screen for managing several characters together.

Possible features:

* view saved characters as a party
* compare levels/classes/species
* open characters quickly
* export a party summary

### Game Master Tools

Possible GM-focused tools:

* quick NPC generator
* tavern name generator
* quest hook generator
* encounter notes
* treasure ideas
* random fantasy details

### Homebrew Support

Possible homebrew features:

* custom species
* custom classes
* custom backgrounds
* custom spell lists
* custom feature tables

### Improved Portrait Workflow

Possible portrait improvements:

* better portrait prompts
* prompt style presets
* portrait gallery
* easier portrait replacement
* better preview window

## Long-Term Ideas

These are bigger ideas that may require major rewrites or new technology.

### Web Version

A browser-based version of Dragon Scrolls.

### Mobile Version

A phone or tablet version if enough users want it.

### Supporter Edition

A possible paid supporter edition could include convenience features such as:

* cleaner installer
* extra PDF themes
* party manager features
* campaign tools
* advanced export options
* premium visual themes

The core goal is to keep Dragon Scrolls useful and friendly while exploring whether a paid version makes sense later.

## Feedback Wanted

Feedback is welcome.

Good feedback includes:

* bugs
* confusing screens
* missing features
* unclear install steps
* ideas for tabletop use
* suggestions for better PDF sheets
* ideas for GM tools
